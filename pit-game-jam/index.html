03 • biblioteca de downloads individuais

Abra a mochila.
Escolha só o que precisa.

Personagens, cenários, objetos, modelos GLB e efeitos de áudio. Todos os downloads são individuais, gratuitos e processados no seu navegador.

Carregando biblioteca…

Onde utilizar cada arquivo? PNG de personagem/item → GDevelop → adicionar objeto Sprite. PNG de mapa → plano de fundo ou sprite (colisão requer objetos/behaviors próprios). GLB → adicionar objeto 3D Model. WAV → folha Events → ação de reproduzir som. Teste imediatamente no Preview. Importante: estes recursos visuais geométricos de reserva foram produzidos por programação, não são imagens de IA; gere pelo menos um asset com PixelLab/Meshy ou outra IA gratuita para cumprir a missão.
Os downloads GLB são props geométricos leves para experimentação. Não substituem um mundo inteiro nem contêm automaticamente controles/física. Abra um starter 3D para câmera/movimento. Os WAV são sintetizados por código e não dependem do ElevenLabs. Para publicar comercialmente com música de terceiros, verifique licenças.

05 • dúvidas que realmente importam

Como usar sem se perder.

Sou aluno. Por onde começo?

Abra o caderno do aluno, escolha a missão atual e siga os passos até o Preview. Para arte, filtre esta biblioteca. Para programação visual, utilize o GDevelop.

Sou professor. Como espelho?

Abra o Mission Control em tela cheia. Cada missão tem sua faixa de tempo e seção do aluno relacionada. Nas demos 2D e 3D há atalhos para o passo correspondente.

Os arquivos do aluno são privados?

Não envie fotos pessoais ou dados sensíveis ao GitHub Pages. A página pública não recebe os dados digitados no caderno; o progresso local fica no computador até o aluno exportar um JSON.

Preciso de conta ou assinatura?

O portal e os arquivos de exemplo não cobram nada. Algumas ferramentas de geração de IA usam contas e cotas gratuitas. Crie as contas com antecedência; se uma falhar, use outra IA gratuita ou recurso-reserva enquanto continua desenvolvendo.
