# PIT GAME JAM IA — CREATOR MODE

Portal público da oficina de 6 horas: https://dev-gabriel-exe.github.io/pit-game-jam/

## Conteúdo
- index.html — portal e biblioteca seletiva de assets.
- aluno.html — caderno do aluno (missões + XP + evidências + exportação JSON).
- professor.html — caderno do professor (roteiro de projeção e tutoriais).
- biblioteca.js — geração local de PNG/GLB/WAV; não exige backend nem serviço pago.
- cover.jpg — cenário visual original gerado por IA para a oficina.

## Importante
O GitHub Pages hospeda apenas arquivos estáticos, não oferece banco de dados central ou armazenamento sincronizado. O progresso do aluno é mantido localmente no navegador via localStorage. Para migrar de computador, exporte e importe o JSON pelo próprio caderno.

Os recursos SVG/PNG, GLB e WAV geométricos/sintetizados disponíveis no portal são de apoio, **não obras geradas por IA**. Para cumprir a missão de criação com IA, cada aluno deve gerar ao menos um asset numa ferramenta generativa gratuita e integrá-lo ao GDevelop.

Os starters editáveis são os oficiais do GDevelop, acessados por links; não são redistribuídos dentro do repositório. O conteúdo do professor é público porque este portal foi explicitamente concebido com acesso a ambas as áreas.
