Não escolha uma ferramenta porque ela é bonita. Escolha porque ela resolve uma intenção de interface.

Ferramenta ≠ identidade

04 • pesquisar, decompor e reconstruir

Três sites. Três jeitos diferentes de aprender design.

GetLayers fornece uma camada visual para a IA reconstruir; Curated ajuda a encontrar referências reais; 60fps permite estudar como produtos reais se movem. O objetivo é sair da cópia cega para a decomposição de padrões.

PROMPT → CAMADAS → INTERFACECinematic depth
GetLayers • AI-native design layers

Não peça “um site bonito”. Dê uma direção visual concreta.

Efeito demonstrado: composição em profundidade + gradiente que acompanha o ponteiro. É uma recriação didática do tipo de camada visual que o GetLayers organiza em templates, cenas 3D, backgrounds, gradients e sections.

Como usar: escolha uma camada pelo clima que você quer, copie o prompt e peça ao agente para reconstruí-la no seu stack. Depois troque conteúdo, cores e estrutura para o problema real.

Grátis: o site mantém um conjunto curado de layers gratuitos, com prompt completo e sem cartão. O acesso completo e a licença comercial ampla fazem parte dos planos pagos.

Curated.design • referências de sites reais

Referência boa é pesquisável.

Interação demonstrada: wall de referências com filtros por linguagem visual. O efeito aqui não é uma animação específica — é transformar inspiração em pesquisa estruturada.

Como usar: defina primeiro o tipo de projeto e depois compare 5–10 sites do mesmo estilo. Observe hero, grid, densidade, tipografia, navegação e uso de motion antes de escrever código.

Grátis: a galeria principal e a navegação por indústria/estilo são abertas. Filtros avançados e buscas salvas fazem parte do Curated Pro.

60fps.design • motion de produtos reais

Não copie a tela. Estude o que acontece entre dois estados.

Efeitos demonstrados: morph, swipe, glow, spring e success/confetti — categorias típicas para decompor uma microinteração em gatilho, transformação, easing e feedback.

Grátis: a coleção pode ser navegada gratuitamente. Hoje o site reúne mais de 2.000 shots de centenas de apps, além de storyboards, filtros e uma área de motion.

Não comece pelo código. Comece perguntando o que você quer aprender da referência.

Awwwards, Land-book, SiteInspire e Mobbin parecem “sites de inspiração”, mas respondem perguntas diferentes: excelência visual, seções, linguagem estética e fluxos de produto.

Awwwards • referência de excelência + tecnologia

“Como os sites premiados resolvem isso?”

Explora Sites of the Day/Month/Year, coleções e filtros por categorias e tecnologia — hoje incluindo CSS animations, WebGL, React, 3D, GSAP, Framer e Webflow.

Acesso: navegar pelas referências é público; existem opções Pro, Academy e submissão paga. Para explorar sem pagar, o acervo público já funciona muito bem como repertório e desmontagem de padrões.

Land-book • pesquisar por seção

“Como outras pessoas desenham esta parte da página?”

Além de sites completos, permite pesquisar seções e tipos de página como pricing, sign-up, careers e about, além de filtrar por estilo, indústria, tipo, tipografia e cor.

Grátis: o plano Basic é gratuito continuamente, com acesso limitado a categorias, sections, motion, filtros e até 3 boards. O Pro expande esses limites.

Experimento acima: altere apenas a seção e perceba como uma busca específica — “pricing section”, por exemplo — é mais útil do que procurar apenas “um site bonito”.

SiteInspire • taxonomia visual

“Que linguagem visual combina com o projeto?”

A coleção pública organiza referências por categorias, estilos, tipos, assuntos e plataformas. Entre os grupos visíveis estão Typographic, Minimal, Grid Layout, Unusual Layout, E-commerce, Portfolio e outros.

Use quando: você ainda não sabe descrever o estilo que procura. Os filtros viram vocabulário: “minimal + grid”, “typographic + portfolio”, “unusual layout”.

Experimento acima: cada filtro reorganiza a mesma coleção. O ponto não é copiar um site, mas aprender a nomear decisões de design.

Awwwards / Land-book / SiteInspire ajudam muito no site. Quando a pergunta vira onboarding, checkout, paywall, configuração ou fluxo mobile, mude de fonte.

06 • hero com vídeo

Vídeo não entra no site. Ele vira parte da composição.

Flow, LTX‑2.5 e outros geradores podem produzir pequenos loops. O front-end transforma esse arquivo em atmosfera: crop, contraste, overlay, tipografia, fallback e desempenho.

DEMO REAL • HERO CINEMATOGRÁFICO

Liberdade em movimento.

Um clipe 16:9 de águia em voo ocupa todo o hero com object-fit: cover, recebe overlay escuro e deixa a tipografia assumir o foco. O mesmo tratamento vale para um vídeo gerado no Flow ou LTX‑2.5.

Vídeo-base gratuito: Palmo Art / Pexels ↗ • se o arquivo externo não carregar, entra automaticamente o fallback incorporado.

09 • receitas mínimas

Copie a ideia. Depois entenda o código.

Estes trechos são deliberadamente pequenos: mostram o mecanismo central por trás do efeito sem transformar o catálogo em um projeto de centenas de linhas.

GSAP + ScrollTrigger: scrub

gsap.registerPlugin(ScrollTrigger)

gsap.to('.produto', {
  scale: 1.35,
  rotate: 8,
  scrollTrigger: {
    trigger: '.secao',
    start: 'top 70%',
    end: 'bottom 30%',
    scrub: true
  }
})
Quando usar: o movimento precisa acompanhar a posição do scroll, não apenas disparar uma vez.

Motion / stagger mental model

const letras = [...titulo]

letras.map((letra, i) => (
  <motion.span
    initial={{ y: 20, opacity: 0 }}
    animate={{ y: 0, opacity: 1 }}
    transition={{ delay: i * 0.035 }}
  >{letra}</motion.span>
))
Quando usar: entrada de títulos curtos, palavras-chave, logos e momentos de destaque.

Hero com vídeo resiliente

<video
  autoPlay muted loop playsInline
  poster="hero-mobile.webp"
>
  <source src="hero.webm" type="video/webm" />
  <source src="hero.mp4" type="video/mp4" />
</video>

.hero video {
  width:100%; height:100%;
  object-fit:cover;
}
Quando usar: loops curtos e atmosféricos. Sempre forneça poster/fallback e comprima o arquivo.

Haikei / SVG como background

<svg viewBox="0 0 1440 320">
  <path
    fill="#3157ff"
    d="M0,160L...L1440,320L0,320Z"
  />
</svg>

/* SVG é vetor: leve e responsivo */
Quando usar: ondas, blobs, divisores de seção e fundos únicos sem depender de JPEG grande.

Spotlight card

card.onpointermove = e => {
  const r = card.getBoundingClientRect()
  card.style.setProperty('--x', e.clientX-r.left+'px')
  card.style.setProperty('--y', e.clientY-r.top+'px')
}

.card::before {
  background: radial-gradient(
    circle at var(--x) var(--y),
    #fff8, transparent 35%
  );
}
Quando usar: cards de produto, pricing ou portfólio. Microinteração simples, sem biblioteca.

Three.js: regra de ouro

// carregue 3D só quando a seção estiver perto
const io = new IntersectionObserver(([entry]) => {
  if (entry.isIntersecting) {
    import('three').then(initScene)
    io.disconnect()
  }
})
io.observe(document.querySelector('#hero3d'))
Quando usar: 3D tem custo. Lazy loading ajuda a preservar LCP e tempo de carregamento.
10 • workflow + MCP

O segredo é combinar ferramentas, não procurar “a ferramenta perfeita”.

01

Referência

MotionSites, Scrolltide, Codrops, Awwwards. Observe ritmo, composição e transições.

02

Estrutura

shadcn, Origin UI, ReUI. Monte componentes sólidos antes de decorar.

03

Personalidade

React Bits, Magic UI, Uiverse. Escolha 1–3 efeitos que combinam com o projeto.

04

Motion

Motion, GSAP ou Anime.js. Controle entrada, interação e scroll.

05

Mídia

Flow/LTX para vídeo; Haikei para SVG; Rive/Lottie para vetores.

06

Validação

Chrome DevTools, Lighthouse e reduced-motion. Bonito sem performance não fecha a conta.

MCP

shadcn

Permite que agentes encontrem/instalem componentes e registries. Excelente para transformar intenção em componente real.

"use shadcn registry para montar um dashboard acessível"
MCP

Magic UI

Componentes animados podem ser pesquisados e instalados pelo agente, útil para hero, marquee, beams, borders e text effects.

"adicione um hero com marquee e animated beam sem exagerar"
MCP

21st.dev

Catálogo enorme; browsing é gratuito, mas acesso amplo via MCP/CLI faz parte dos planos Builder. Use para buscar componente por “vibe”.

"find a restrained editorial pricing component"
DEVTOOLS

Chrome DevTools

Use Performance, Network, Lighthouse, FPS e CPU throttling para provar se o efeito ficou pesado.

Performance → record → scroll → long tasks / layout shifts
SKILL

Frontend Design

Trate como uma regra de geração: peça hierarquia, contraste, tipografia, espaçamento e consistência antes de pedir “mais animação”.

"preserve hierarchy; avoid generic AI gradients and repeated cards"
SKILL

Web Design Guidelines

Depois da estética, faça a segunda passada: acessibilidade, estados de foco, responsividade, legibilidade e preferência por movimento reduzido.

"audit focus, contrast, semantics, mobile and reduced-motion"

Mesma empresa. Quatro sites que não parecem parentes.
