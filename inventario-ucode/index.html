Coleta automática do Windows

Novo: coletor EXE para Windows 10/11 de 64 bits, testado com execução real e validação do JSON. Não depende de abrir o PowerShell. O aplicativo recolhe apenas dados técnicos e não solicita acesso de administrador para a coleta básica.

1. Baixar coletor uCode (.exe)

Baixar uCode-Coletor.exe (68 MB)

Abra o executável no próprio computador. Ele coleta automaticamente, cria o arquivo JSON, mostra onde salvou e oferece botões para abrir a pasta ou copiar o JSON. Não instale programas adicionais. Este EXE ainda não possui assinatura digital; confirme sua procedência e autorização com a empresa antes de executar.

Alternativa: PowerShell

Se o computador não aceitar o EXE, existe a opção PowerShell abaixo. Só execute scripts com autorização da empresa e não contorne bloqueios de segurança.

  1. Abra esta página no PC e baixe o script corrigido de coleta (.ps1), ou copie o conteúdo dele.
  2. Abra o PowerShell e execute o conteúdo copiado. Se a execução de arquivos estiver bloqueada, não altere as políticas da empresa sem autorização.
  3. O script atualizado salva um arquivo ucode_inventario_NOMEPC_DATA.json. Ele tenta a Área de Trabalho, depois Downloads, Documentos e uma pasta temporária. Confirma que o arquivo existe, mostra o caminho completo e abre a pasta no Explorador. Também copia o JSON para a área de transferência.
  4. Para importar, escolha o arquivo abaixo ou, se estiver usando o site no mesmo PC, cole diretamente o texto do PowerShell no campo JSON usando Ctrl+V. Se precisar transferir ao celular, utilize apenas meios corporativos autorizados. Nunca envie senhas nem arquivos pessoais.
  5. Revise modelo, serial, HD/SSD, capacidade total e espaço livre, além dos softwares. Complete setor, utilização, licenças, conectividade física, problemas e fotos; salve.

A coleta de softwares lista o que está instalado; não prova licença paga nem frequência de uso. Se não surgir nenhum arquivo, fotografe a mensagem final do PowerShell e o caminho que ele mostrou. O script só confirma sucesso depois de verificar a gravação.
